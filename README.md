## The Last Firefly

_The forest used to glow with a thousand small lights. One by one, they went dark.
You're the last firefly-born, and your own glow is fading too.
Find what's left of your kin. Let their light carry you home._

A short 2D platformer I made for Hack Club Jumpstart. You're in a dark forest, and your bug glow is the only light you've got. It keeps running low, so you have to find other firefly bugs to keep it going. The game currently has one level.

[Play it here](https://kash-mm.itch.io/the-last-firefly)

### Controls
Move: A / D or arrow keys
Jump: Space, W, or up arrow

### Made with
- Godot 4
- Tileset: [Free 2D Swamp Tileset Pixel Art](https://free-game-assets.itch.io/free-swamp-2d-tileset-pixel-art)
- Character (edited): [Free Tiny Hero Sprites Pixel Art](https://free-game-assets.itch.io/free-tiny-hero-sprites-pixel-art)
- Music: [Free forest music from pixabay.com](https://pixabay.com/music/search/forest/)

### Run it yourself
Open the project in Godot 4 and hit play OR play it on the web using the itch.io link above.
